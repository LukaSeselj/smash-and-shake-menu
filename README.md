# Smash & Shake Digital Menu

Simple static QR menu page for Smash & Shake.

## Structure

- `index.html` - menu content
- `css/style.css` - styles and brand colors
- `assets/` - logo, QR code and future images
- `js/main.js` - optional scripts for later

## Development

Open `index.html` directly in browser or use VS Code Live Server.

## Deployment

Can be deployed on Vercel, Netlify or GitHub Pages.
